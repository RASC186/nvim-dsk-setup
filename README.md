# Neovim for Web Development

This project contains scripts and configuration files to install and configure Neovim for desktop software development.

## Prerequisites

This project installs all prerequisites automatically (superuser credentials necessary).

## Instructions

To install Neovim and set it up for desktop software development, run 

```
./install
```

To uninstall Neovim and remove all configuration files/directories, run

```
./uninstall
```
